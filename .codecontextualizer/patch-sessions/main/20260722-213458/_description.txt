Intención: Implementar pruebas automatizadas (puertas de calidad) para el ciclo de vida de @Defer, la resurrección de estado (Stateful/Redis) y el generador de Web Components, garantizando el cumplimiento del Definition of Done del backlog vigente.

Alcance: Se crean tres nuevos archivos de test: `DeferLifecycleTest.java` (valida hilos virtuales y reactividad diferida), `StateResurrectionTest.java` (valida serialización JSON de componentes completos) y `GenerateComponentsMojoTest.java` (valida la generación de código del plugin). Motivo: El proyecto se encuentra en fase de estabilización (0.0.1-SNAPSHOT) y el backlog exigía garantías robustas sobre la ejeción asíncrona, persistencia de estado en arquitecturas distribuidas y la generación AOT, previniendo regresiones graves antes de un lanzamiento.
